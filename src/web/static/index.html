  • 一般對話其他問題

    對話摘要

    系統會在每一輪對話後整理重點。按下「結束對話」時可以選擇是否儲存摘要；選擇儲存後，會出現「下載摘要」按鈕，可下載 Markdown 檔案。

    注意事項

    • 客戶資料皆為虛構的展示資料。
    • 法規回覆僅供參考，並附上條號出處，不構成法律意見。
    • 系統只提供資料摘要，不做授信核准或拒絕的判斷。
    • 貸款試算的結果由程式計算，僅供參考；方案為示範用虛構資料，實際條件以核貸結果為準。
    • 問題內容會傳送至語言模型服務（Gemini API）處理，請勿輸入真實的個人資料。
